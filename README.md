# GoodFirstIssue
GoodFirstIssue is an open-source web application designed to help new contributors discover beginner-friendly GitHub issues categorized by labels like **Good First Issue**, **Starter Task**, and **Help Wanted**.

---

## 🚀 Recent Updates & Features

- **Theme Toggle:** Added a Dark Mode / Light Mode toggle switch for better user accessibility.
- **Improved Language Selection:** Formatted language options into a structured, interactive dropdown list with custom label prompts.
- **Enhanced UI Layout:** Applied clean, rounded card borders with soft shadows to organize query controls.
- **API Fixes:** Improved GraphQL query authentication and error handling for fetching GitHub issues.
- **hover effect : ** apply hover effect that can change the color when mouse hover on the particular sections like :- "goodFirstIssue" , "helpWanted" , "starter task"
